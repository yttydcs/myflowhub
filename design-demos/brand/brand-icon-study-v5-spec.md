# MyFlowHub 品牌图标精修 V5 · Production refinement brief

> 状态：V4 方向已由用户选定；V5 是同一方向的几何与生产精修。V4 保留为决策基线，正式 `myflowhub-icon.svg` 暂不替换，也不发送给 Desktop 实现任务。

## 1. 精修目标

V5 不再讨论“画什么”，只解决 Coupled Seam 如何成为可长期生产的标志。目标受众是项目开发者、未来用户以及需要在系统托盘、桌面应用、文档和网站中看到该标志的人。观看距离横跨 16px 系统托盘到 512px 品牌展示，因此同一个方向必须形成多套光学校正版，而不能将大图机械缩小。视觉温度继续保持冷静、可信、精确和舒适；禁止新增六边形、树枝、圆点、箭头、渐变或发光效果来补充解释。

核心 idea 不变：两个独立节点在可信边界内建立定向连接。深色单元和浅色单元严格来自同一条 Keyed Cell 母形；中央 Coupled Seam 是主体分离与关系成立的共同证据。标志不直接绘制 Resource、Subscription、Command、Transport 或物理树，它只代表 MyFlowHub 的最小关系单元。

## 2. 三组微调结论

- **V4 baseline**：识别稳定，但 24px 单色时接缝略紧，中央负空间接近普通链环。
- **A · Calibrated Seam（采用）**：键口纵向由 12 单位调整为 13 单位，入口由 8 单位调整为 9 单位；全尺寸隔离缝由 7 调整为 9。外部轮廓和双色比例保持不变，第一印象不发生变化。
- **B · Directional Key（淘汰）**：L 形键口虽然强化父方向，但形成锯齿和拼图联想，破坏稳重感。
- **C · Tight Coupling（淘汰）**：缩短两单元中心距离后整体更紧，但中央接缝退化为普通圆孔，原创性和语义同时下降。

## 3. 几何规范

- 母形源网格：`96 × 96`；成品 symbol 画布：`256 × 256`。
- 两单元中心：`(96, 96)` 与 `(160, 160)`；旋转分别为 `45°` 与 `225°`；缩放均为 `1.2`。
- 主标全尺寸接缝：`9` 个源网格单位；compact：`24`；tray：`30`。
- 主标占据画布约 82%，视觉中心位于 `(128, 128)`，不依靠容器阴影维持平衡。
- 外轮廓保持圆角，内部键口保持直线；不得改变两单元的相对位置、独立旋转或比例。
- clear space：四周至少为主标总高的 `25%`；仅 16–20px 系统槽位可按平台限制缩减。

## 4. 色彩规范

- Primary / Mineral Blue：`#3F6F8F`
- Secondary / Mineral Light：`#86B2C9`
- Ink / Graphite：`#202222`
- Canvas / Warm White：`#F5F5F2`
- Inverse：`#F5F5F2`

双色只用于浅色或中性背景；复杂背景、单色打印、托盘和深色低对比环境使用 mono / inverse。绿色仍只表示连接状态，不能进入品牌 symbol。

## 5. 资产路由

- `myflowhub-symbol-v5.svg`：品牌主标，建议 32px 以上。
- `myflowhub-symbol-v5-mono.svg`：浅色背景单色主标。
- `myflowhub-symbol-v5-inverse.svg`：深色背景反白主标。
- `myflowhub-symbol-v5-compact.svg`：20–31px 彩色版本。
- `myflowhub-symbol-v5-compact-mono.svg`：20–31px 单色版本。
- `myflowhub-tray-v5.svg` / `myflowhub-tray-v5-inverse.svg`：16px 系统托盘与 favicon。
- `myflowhub-app-icon-source-v5.svg`：1024px 未遮罩方形应用图标源；圆角和阴影由平台处理。

## 6. 字标与排版

当前研究板使用 `Segoe UI Semibold` 作为临时字标，与 Desktop 工具界面保持一致。symbol 与 `MyFlowHub` 的水平间距为 symbol 高度的 `28%`；字标基线按视觉中心上移约 symbol 高度的 `1.5%`。在品牌正式发布前仍应决定是否保留系统字标，或为 `M / F / H` 做轻量定制；本轮不把临时字体轮廓化为正式资产。

## 7. 验收门槛

- 16px 下仍能看出两个主体，中间不得粘连。
- 24px 单色与反白版本不能依赖颜色判断两个节点。
- 32px 以上使用完整版本时，接缝不得显得像额外的第三个主体。
- 应用图标经过小圆角、大圆角和圆形遮罩后均不得裁切或偏心。
- HTML 研究板在 1440px、768px、390px 宽度下无横向溢出；所有本地 SVG 加载成功，控制台错误为零。

## 8. Form 推导

- 叙事角色：选定方向后的生产精修与验收板。
- 观众距离：1m 桌面审阅，同时包含 16px 原尺寸实物检查。
- 视觉温度：安静、精确、可信，不古板。
- 容量：首屏只确认最终主标；随后依次呈现微调差异、资产分工、尺寸和边界。
- 视觉母题：两个同源 Keyed Cell 形成一条不可删除的 Coupled Seam；形式直接来自项目的节点与可信连接关系。

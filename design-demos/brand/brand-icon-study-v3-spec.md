# MyFlowHub 品牌图标研究 V3

> 本文件是选型阶段的设计依据，不是当前生产品牌规范。已有图标与 V1/V2 研究均保留，直到用户明确选定方向。

## 1. 品牌命题

MyFlowHub 不是一个泛化的“设备联网工具”。项目的长期特征是：运行期只有一棵权威节点树；经过认证的父子链路同时承担路由与 authority；每个 Node 拥有可扩展 Resource；Subscription 让 Variable、Stream、Topic 等资源持续可观察；Command 补足主动操作。TCP、Bluetooth、QUIC、串口等承载可替换，但不改变上层语义。

因此主图形只表达一句话：**一个可信节点边界，组织并向外提供持续流动的资源。**

它不直接画网络拓扑，不枚举资源类型，也不画具体传输协议。否则图标会像架构图、芯片图标或普通 IoT 产品，且新增 Resource 类型时品牌图形会过时。

## 2. 视觉性格

- 稳重但不古板：主体轮廓有重量，内部留白保持呼吸。
- 技术但不赛博：使用精确几何，不使用霓虹、渐变、发光和伪电路装饰。
- 极简但不通用：依靠自定义负空间、比例和切口形成可识别轮廓，而不是图标库常见的节点连线。
- 友好但不玩具化：圆角只用于缓和转折，不使用表情式双点和过度饱满的胶囊。

## 3. 语义映射

| 架构事实 | 视觉映射 | 明确不采用 |
| --- | --- | --- |
| Node 是唯一拓扑与 authority 主体 | 一个连续、可独立识别的外部轮廓 | 多个平级圆点组成的网络图 |
| 父子链路已认证后成为权威边 | 单一的上游入口、键口或定向切口 | 第二棵权限树、锁头、盾牌 |
| Resource 由 Node 拥有 | 位于主体内部或由主体直接形成的空间 | 漂浮在外部的资源小图标 |
| Subscription 是一级关系 | 连续通道、贯穿负空间或节奏重复 | 无穷符号、广播波纹 |
| Resource type 可扩展 | 三个只表示“复数资源”的抽象节拍 | 在主图标中固定 Variable/Stream/Topic 图例 |
| Transport 可插拔 | 不进入主图形 | 蓝牙、Wi-Fi、USB、电路引脚 |

## 4. 几何规范

- 母版使用 `256 × 256` 坐标；视觉安全区不小于 22。
- 主轮廓尽量落在 24–232 内；视觉中心允许向上修正 2–4 单位。
- 每个候选最多使用两类转角语言：圆角与 45°/60°切角不能同时泛滥。
- 主色不超过两级；任何版本都必须能退化为单色而不丢失识别。
- 16–32 px 使用独立 compact 图，不机械缩小母版；最细实体或负空间不得低于 2 px@16。
- 不依赖透明叠色、滤镜或渐变。深色模式只换 token，不改变几何。

## 5. 色彩

- Graphite：`#202222`，字标与单色深版。
- Mineral Blue：`#3F6F8F`，品牌主色，承接 Desktop 的主操作色。
- Mineral Light：`#86B2C9`，用于次级结构，不承担状态语义。
- Warm White：`#F5F5F4`，浅色负空间与应用底色。
- Night：`#191A1A`，深色展示底。
- Green 不进入品牌主体；`#34785A` 继续只表示“已连接/成功”。

## 6. V3 三个方向

### J · Node Key / 节点键

用一个带方向性的实体轮廓定义 Node，通过上方键口和内部三段负空间表达 authority 入口与多 Resource。它应当像一个专有的工业符号，而不是容器里摆三个圆点。

### K · Flow Fold / 流折

用一条连续折带建立父链、Hub 与资源出口。重点是连续性和订阅，不画封闭外框。折带必须在单色下仍能成立，且不能读成字母、闪电或普通分享图标。

### L · Resource Ledger / 资源谱

用同一块主体中的节拍切口表达“节点持有一组可扩展资源”。它更安静、更像专业工具的品牌印记，弱化网络与运动隐喻，强调目录、秩序和可组合性。

## 7. 淘汰标准

出现以下任一情况即不进入推荐：

- 32 px 时需要文字解释才能看出主体；
- 第一联想强烈落到机器人脸、花朵、相机光圈、风扇、医疗十字、云服务或加密货币；
- 单色版本塌成一团，或深色版本必须使用描边补救；
- 与现有 Desktop 矿物蓝/石墨灰界面并置时过于活泼或过于硬核；
- 为了表达架构而依赖四种以上零散小元素。

## 8. 最终交付要求

每个方向都必须展示：母版、compact、小尺寸阶梯、浅/深模式、单色、应用磁贴、侧栏/托盘和横向字标。选型之后再清理未选资产，并从选中方向导出生产 SVG/PNG/ICO/ICNS；本轮不修改 `myflowhub-icon.svg`。

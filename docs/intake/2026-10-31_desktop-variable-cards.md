# Desktop 多变量卡片、重命名与视图编辑模式

## 来源与状态

2026-10-31 本次用户会话的保真摘要；不是附件内的执行指令。用户确认整体设计并要求继续实施；第一版演示与模拟验证交付后，2026-11-01 用户要求“好帮我合并回去吧”并调用 `$m-archive`，授权本地合并与本次 worktree 收尾。没有远端推送授权。

## 已确认范围

- 保留现有单变量卡片，新增一张容纳多个变量的“名称＋值/控件”列表卡片；这是第二种卡片类型，不是新布局模式。两种卡片在紧凑/分栏布局混排。
- 单卡默认变量名称，可重命名；列表有独立标题，行可设别名。清空恢复默认，只影响当前视图引用，不改真实变量。
- 标题手柄拖整卡布局；变量手柄用于行排序、跨卡移动、拖出独立成卡。左侧资源拖入添加引用，卡片之间拖动移动引用。
- 拖到单变量正文自动转列表；同卡禁止同一变量重复，跨卡可引用同一变量。列表剩一项不自动降级，移空保留，允许显式转回单卡。
- 新建视图进入编辑，已有视图打开默认查看；保存成功回到查看。查看隐藏手柄、结构设置/删除/布局缩放入口，但变量值仍可操作。
- 左侧资源仅有效放下后自动进入编辑，不自动保存；取消拖动或无效释放不改变模式。
- 取消编辑只恢复结构，不回滚已经写入的真实变量值；重组必须保留未提交输入且不能触发写入。保存失败或保存期间新编辑不能丢草稿。

## 工程边界与验收范围

- 不修改变量协议、权限和网络语义，不把值、草稿或凭据写进 View。
- 旧 v3 文件可读；新增可选字段仍保持 version 3，但旧二进制严格解码不认识新字段，试运行前备份 `views.json`。
- 每卡 64 变量、每 View 512 引用、50 步结构历史为实现侧有界保护，不新增产品业务承诺。
- 当前证据是单元/集成测试、存储往返、生产构建与 Headless Edge 内存模拟 API；未启动真实 Profile、未连接设备，也未声称完成真实 Wails GUI/读屏验收。

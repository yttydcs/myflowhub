# 节点拓扑发现

状态：Current，2026-09-06 实现及验收通过。原始需求见[讨论记录](../intake/2026-09-06_depth-scoped-topology-discovery.md)，技术合同见[拓扑发现规格](../specs/topology-discovery.md)。

网络的领域对象只有节点、网络和资源。节点是能力提供者，不等同于物理设备；设备、进程和插件不是拓扑对象。

## 需求

- 在已知节点处读取其子树。默认从直接父节点读取一层；一次查询必须返回所请求范围内的完整结果。
- depth 是非负整数：1 表示直接孩子，n 表示最多 n 层后代，0 表示不限制后代深度。响应始终包含起点。整网查询要求已知网络根及相应授权。
- 浅层导航、深层查询、目录读取和业务资源操作分别授权。树不可见不等于资源不可访问；不枚举或猜测未知 Node ID。
- 父节点复用自己维护的子树状态。请求不触发对后代的逐节点采集；允许传播和刷新周期产生短暂延迟。
- Desktop 首次展示一层，展开已知节点时加载其孩子。未加载、加载中、空、过期、禁止访问、不可达、不支持和其他错误必须区分。
- 搜索仅覆盖已加载节点；完整子树加载由用户在明确起点主动触发。失败不扩大范围、不改换起点、不自动回退到全量快照。
- 目录按选中节点和当前 View 引用独立加载；目录超时不得阻塞树。资源暂未发现时保留 View 布局和业务草稿。
- 缓存仅存在于当前 Profile/连接的内存中。切换、断连、重连及移除分支后，旧异步响应不得恢复失效关系。
- 超出协议或本地缓存上限必须明确失败，不可把截断结果称为完整。

## 范围

本轮只实现深度查询与 Windows Desktop 按需导航。旧 read/subscribe 快照兼容；不恢复 Flow、Android、嵌入式或 owning SDK，不引入实时事件总线、服务器搜索、分页或通用 payload 权限引擎。

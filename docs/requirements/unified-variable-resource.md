# 平台通用 Variable

## Status

已实现 R2，并按用户后续手动验收请求完成 Desktop 交互调整。2026-10-09 归档，验收与本地合入状态见 [变更记录](../change/2026-10-09_unified-variable-contract.md)。产品尚未发布。

## Product intent

网络只认识节点、网络和资源。Variable 是平台资源类型，节点拥有并提供变量实例。Metrics 等产品只实现采集、业务约束或外部执行适配，不另行定义消费者必须认识的变量包装协议。

统一变量是后续任意节点协作和自动化的基础。本轮不选择自动化模型。

## Requirements

1. 平台统一变量描述、值、版本、状态、读取、条件写入及订阅契约；保持 owner NodeID + resource name 寻址与现有权限裁决。
2. 提供者使用平台标准语法声明实例的值类型、范围、步长、枚举、单位及结构；业务校验可以更严格，不能削弱平台校验。
3. 布尔和数字保留真实类型。false、0、空字符串、null 与没有可用值必须能够区分。对象和数组按相同契约表示，不因领域结构不同而另造变量类型。
4. 获授权消费者能从标准操作取得足够的值定义和当前状态，无需预装提供者专用 schema，不能通过资源名猜测格式。
5. 变量具有当前值和单调修订；读取结果足以进行条件写入，不应强制具有 subscribe 权限才能拿到写入所需版本。订阅先发一致快照，再发有序更新。
6. 远端只写值，不得任意改定义、权限、revision 或采样质量。只读、可写能力与最终授权分别表达，展示控件不授予权限。
7. 需要外部执行的可写变量，必须经 owner 的业务处理后反馈真实结果；不能只更新内存中的显示值。不能确认执行结果时，不伪报成功。
8. 可用、陈旧、不可用状态必须明确；陈旧时可保留最近真实值，不用零、空字符串或 false 代替采集失败。
9. Desktop 统一显示和编辑布尔、数值、枚举、文本、对象和数组。只读值提供状态/数值/进度等展示；可写有界数值提供滑块和数字输入，可写布尔提供开关；Inspector 保留 Reset/Apply；View 自动应用离散操作，数字和单行文本按 Enter 或失焦提交，多行文本/高级 JSON 按失焦提交。提交期间控件显示加载态，离散控件在 owner 确认后更新效果；错误保留草稿和恢复入口。
10. 持续更新不能覆盖未提交草稿；冲突、失效、断连、撤权及资源替换有明确状态。关闭组件或切换 Profile 后释放订阅，不接受旧会话的迟到结果。
11. 值定义只能是有界数据，不能包含可执行组件、远程代码或自动发起请求的指令；大小、复杂度、数值精度与缓存均有明确边界。
12. 平台所有当前第一方 Variable 提供者、SDK、Desktop 及相关调用方一次性替换为新契约，不要求旧客户端、旧 wire、旧 API 或旧变量视图可用；不引入双版本 codec、legacy renderer、转发别名或自动格式迁移。
13. Metrics 可控变量统一使用标准 write，删除被其取代的 /set 和对应旧协议类型/调用方。本轮只移除被新变量契约取代的实现；具有独立业务语义的其他 Command 不因名称旧而删除。
14. 身份、权限和数据保护仍然有效。不需要兼容不是删除本地 Profile、身份、策略、配置或历史数据的授权；不为它们额外开发兼容或迁移器，联调使用隔离的新格式 fixture。

## Scenarios and acceptance

- 一个从未登记到 Desktop 内置 schema 的节点声明布尔、百分比、枚举、对象变量，当前 Desktop 可通过网络读取定义并正确呈现。
- Metrics 的电量、CPU、网络状态分别表现为平台数值/布尔变量；音量和静音的通用编辑通过实际 actuator 验证。
- 两个消费者并发写入，过期版本被拒绝；旧资源实例的草稿不能写进重新注册的同名资源。
- 采样值未变而时间更新时，界面保留草稿；实际值改变时显示冲突，不能静默重基用户写入。
- Catalog、管理、文件与 Clipboard 的领域功能通过同步更新的公共 SDK 工作，禁止只验收 Metrics。
- 旧 Variable payload、旧写请求明确拒绝；Catalog 不再发布 Metrics /set，源码与生成物不存在本轮保留的旧格式解码、别名或 deprecated 桥接。

## Non-goals

本轮不新增网络对象、不设计 Flow、手势/眼神识别、插件市场、任意资源类型的远程 schema 服务、异步外部执行编排或全局变量名称空间。被新变量契约取代的旧实现必须在本轮删除；其他无关历史协议清理和对外发布不在本轮范围。

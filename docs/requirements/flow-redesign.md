# Flow Redesign

## Status

Deferred / 待办。当前 Flow 实现已移除，重新设计尚未选型，也未进入实现阶段。
先减少现有代码演进对早期 Flow 模型的依赖，再讨论通用自动化能力。

## Product Intent

目标是通用的节点协作平台，让节点提供的能力能被发现、组合和自动化调用。
剪贴板、文件和通知协作只是应用场景，不限定平台的能力范围。

网络模型只认识节点、网络和资源。节点是提供或使用能力的参与者，不等同于物理设备。
同一设备可以承载多个节点，例如提供邮件通讯资源的节点；部署位置不成为网络模型的对象。
网络模型没有插件概念；某个节点可以在内部通过插件实现能力。

## Current Removal Boundary

- 移除早期 Flow 执行器、Hub 装配、内置资源与 schema、Go SDK FlowClient、Android Flow 示例入口及其专属测试/fixture。
- 保留通用资源、Collection、调用、订阅、授权与网络机制，以及文件和通知能力。
- 不读取、执行、迁移或删除已有 `flow.json`；新启动的 Hub 不再创建该文件。
- 旧 Flow 调用不再可用；不提供兼容执行器或自动重定向。未来实现不能凭旧资源名自动继承旧授权。
- 历史实现可从 Git 找回，旧规格保留为历史材料；不会继续作为当前交付门禁。
